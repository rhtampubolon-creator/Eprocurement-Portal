# Dashboard Reference Layout

Layout dashboard mengikuti referensi yang disetujui:

- Sidebar Workspace berada di kiri dan satu grid dengan konten utama.
- Menu: Dashboard, Procurement, Vendor Management, Contract Management, Reporting (Soon).
- System Information dan Announcement tetap di sidebar kiri.
- Quick Access berisi Procurement, Vendor Management, dan Contract Management.
- Setiap Quick Access mempertahankan Update History.
- Recent Activity menjadi panel utama yang lebar.
- AI Procurement Reminder berada di panel kanan.
- Login, Sign Up, session, role, Admin Tools, backend, dan sinkronisasi tidak diubah.

Jalankan melalui Live Server dan lakukan hard refresh setelah mengganti paket.
