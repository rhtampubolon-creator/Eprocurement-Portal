# UI Reference Fix

Perbaikan ini menata ulang tampilan halaman utama agar konsisten dengan layout referensi yang disetujui.

Perubahan utama:
- Satu sistem visual biru, putih, dan abu netral.
- Font antarmuka modern berbasis system sans-serif.
- Quick Access berurutan: Procurement, Vendor Management, Contract Management.
- Recent Activity tetap menjadi panel utama yang lebar.
- AI Procurement Reminder tetap berada di panel prioritas kanan.
- System Information dan Announcement tetap berada di sidebar.
- Sidebar menjadi drawer pada tablet dan ponsel.
- Tampilan tidak bergantung pada browser zoom untuk memperoleh proporsi yang benar.
- Login, session, role, Apps Script, Google Sheet, reminder logic, dan backend tidak diubah.
