# Perubahan Header Khusus Buyer

Paket ini menggunakan `EProcurement_Reference_Fixed (4).zip` sebagai dasar.

## Vendor Management

- Judul `Vendor Management` dipindahkan ke tengah baris putih.
- Menu `Action` disembunyikan khusus Buyer.
- Search dan tabel tetap tersedia.

## Contract Management

- Judul `Contract Management` dipindahkan ke tengah baris putih.
- Menu `Action` disembunyikan khusus Buyer.
- Search dan tabel tetap tersedia.

## Procurement

- Tombol `Dashboard` disembunyikan khusus Buyer.
- Tulisan `Admin Procurement` dipindahkan ke tengah baris putih yang sama.
- Menu `Action`, Search, sidebar, dan tabel tetap dipertahankan.

Tampilan Procurement Admin dan Super Admin tidak diubah oleh aturan header ini.
# Koreksi Header Buyer (Outer Module Header)

Perubahan kini diterapkan pada header pembungkus modul di halaman utama,
sesuai posisi yang ditandai pada gambar pengguna.

- Vendor: Dashboard luar disembunyikan, Vendor Management dipusatkan, Action modul disembunyikan.
- Contract: Dashboard luar disembunyikan, Contract Management dipusatkan, Action modul disembunyikan.
- Procurement: Dashboard luar disembunyikan, Admin Procurement dipusatkan, Action modul tetap tersedia.
- Aturan hanya aktif untuk role BUYER.
