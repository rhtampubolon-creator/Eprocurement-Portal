# Visual Update v2.1

Perubahan ini hanya menyentuh tampilan dan navigasi frontend utama. Fungsi autentikasi, session, role, backend Apps Script, serta modul procurement tetap dipertahankan.

## Perubahan

- Sidebar utama baru dengan Dashboard, Procurement, Vendor Management, Contract Management, dan Reporting.
- Bidder List tidak menjadi menu mandiri. Bidder List tetap berada di dalam Admin Procurement.
- Google Sheet dan Apps Script tetap berada pada Admin Tools untuk Super Admin.
- Guidelines dan Help ditempatkan pada header.
- Hero dashboard dan card visual dirapikan agar konsisten dengan desain login.
- Navigasi aktif mengikuti modul yang sedang dibuka.
- Tampilan responsif untuk laptop, tablet, dan mobile.
- Reporting ditampilkan sebagai rencana modul dan belum membuka fungsi baru.

## File yang diubah

- index.html
- style.css
- script.js

Tidak perlu deploy ulang codegs.js untuk pembaruan ini.
